== Description ==
This plugin connects your WooCommerce store to Zooda. It automatically sends your products metadata, descriptions, prices, and stock status to Zooda so your AI chatbot is trained on real-time inventory.

== Installation ==
1. Zip the `zooda-woocommerce-sync` folder into `zooda-woocommerce-sync.zip`.
2. Go to your WordPress Admin Dashboard -> **Plugins** -> **Add New** -> **Upload Plugin**.
3. Select the zip file and click **Install & Activate**.
4. Navigate to the new **Zooda Sync** settings page in your WordPress sidebar settings.
5. Paste your unique connection API key from your Zooda Client Dashboard.
6. Verify the Zooda API Base URL matches your Zooda instance host environment.
7. Click **Save & Sync Now**.

== Features ==
* **Bulk Upload**: Sync your entire catalog in a single action when setting up.
* **Real-time Event Sync**: Automatically uploads new products, updates details, and handles stock level adjustments when they occur.
* **Deletion Propagation**: Automatically removes products from your Zooda catalog database when they are trashed or deleted in WordPress.
